## 经验教训 — 三个根本问题

- **「先做再想」** 确定环境行动优先高效，不确定环境确认优先才高效；错在把前者用于后者。已由三层拦截结构性解决（SOUL.md）
- **「自然语言模糊」** 关键约束必须结构化表达（控制流标记 / 定量推理 / 精确匹配）
- **「方案思维」** 先定义需求（谁+场景+痛点）→ MECE 全景 → 选最优路径。商业变体：有数据就想多跑品类，跳过"谁会付钱"（学术验证≠商业验证）
