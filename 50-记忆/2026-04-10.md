### v2 补充：多维表格数据提取

**问题**：初始版本丢失了嵌入的多维表格数据（高潜力队长清单、华东宣讲登记表等）

**解决过程**：
1. `docs +fetch --format raw` 获取原始块级 JSON（115KB），内容在 `markdown` 字段中
2. 原始 markdown 包含 `<lark-table>` HTML 标签格式的表格，共 7 个表 158 行
3. 用 Python 脚本解析 `<lark-table>...<lark-tr>...<lark-td>...</lark-td>...</lark-tr>...</lark-table>` 提取全部行数据
4. 用 `docs +update --mode overwrite` 覆写文档，完整还原所有表格

**关键发现**：
- 飞书 Wiki 中 `<sheet token="xxx"/>` 引用的是**电子表格嵌入**，不是独立 Base 应用
- Spreadsheet API (`sheets +read`) 无法读取这类嵌入 token（返回 invalid）
- 实际表格数据以 **HTML 格式**（`<lark-table>`）存储在文档原始 markdown 中
- 正确提取方式：解析 raw JSON → 提取 lark-table HTML → 转为 Markdown 表格

### v3 修正：二维码图片数据恢复

**问题**：联系方式列中，源文件的二维码（微信图片）全部丢失——v2 版本只提取了文本内容，74 张 `<image token="..."/>` 格式的内嵌图片被忽略

**解决过程**：
1. **定位图片数据**：原始 markdown 中联系方式列的空单元格实际包含 `<image token="xxx" width="784" height="1408"/>` 标签，共 **75 个图片引用**（表2:40张, 表3:7张, 表4:5张, 表5:17张, 表6:5张, 表1:1张）
2. **下载方案探索**：
   - `drive +download` → HTTP 403（bot 无权限）
   - `api GET /drive/v1/medias/{token}/download` → HTTP 403（tenant_token 无权限）
   - `docs +media-download` → HTTP 403
   - ✅ **`docs +media-preview` → 成功！** （唯一可用路径）
3. 批量下载 74 张唯一图片到本地 `qrcode_images/` 目录（~40MB）
4. 上传 74 张图到目标文档（`docs +media-insert`）获取新的 file_token
5. 尝试在 Markdown 中用新 token 引用 → ❌ 飞书 Markdown 更新 API 不支持 `![](token:xxx)` 图片语法
6. **最终方案**：生成完整 HTML 文件（含所有 75 张二维码图片 + 148 条记录），同时飞书文档标注图片位置

**关键发现**：
- 飞书文档内嵌图片有三种 token 类型：image token（预览）、file token（文件）、block token（块级）
- `docs +media-preview` 可用 user_access_token 下载 image token 对应的二进制数据
- `docs +media-insert` 可上传本地文件并获得 file_token
- 但 **Markdown 更新 API 不支持任何形式的图片内嵌**（不支持 `@file:`、`token:`、本地路径）
- 完整图片展示需通过 HTML 或直接操作 Block API 实现

## 客户地图标注任务

### 任务
将订单简表中的客户地点在泰州地图上用爱心标注，区分泰州/非泰州地区，脱敏到小区名，生成印刷级高分辨率图片

### 技术路线
1. pandas 读取 .xls → 正则脱敏（去门牌号/栋/室，只留小区名）
2. 高德 Web 服务 API 地理编码（需 Web服务类型 key，非 JS API 类型）
3. folium 生成 HTML 地图 + 高德中文底图瓦片
4. playwright chromium headless 截图为 8000x8000 / 300DPI PNG

### 关键发现
- 高德 key 类型必须匹配：JS API key 不能调 Web 服务 API（返回 USERKEY_PLAT_NOMATCH）
- 地理编码需指定城市参数，否则同名小区会定位到全国任意位置
- OSM Nominatim 对中国小区几乎无法识别，必须用国内 API
- 高德 API QPS 限制约 5次/秒，间隔 0.4s 较稳妥，超限返回 CUQPS_HAS_EXCEEDED_THE_LIMIT
- folium + 高德瓦片底图在 playwright headless 中可正常加载（需 8-15s 等待）

### 脱敏规则
- 正则去除：`-\d+\d+`、`\d+号`、`\d+栋`、`\d+室`、`\d+幢`、括号内备注
- 保留：小区名/村名/路名（如"和福花园"而非"和福花园4-107"）
