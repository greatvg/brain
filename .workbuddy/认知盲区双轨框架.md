# 认知盲区双轨框架 v1.0

> 2026-08-24 荣总与森林达成共识。本框架为长期认知基础设施，所有新任务按此设计。
> 方法论来源（均已于 2026-08-24 检索验证）：
> - Kegan & Lahey《Immunity to Change》(2009) 四栏免疫地图 — ✅已验证（mindsatwork.com 官方源）
> - Tetlock《Superforecasting》/ Good Judgment Project 预测校准 — ✅已验证（IARPA 实验，1小时训练提升预测准确率6-11%，持续4年）
> - Padesky CBT 7栏思维记录（1983）— ✅已验证（NHS/APA 推荐）
> - 双轨组合设计本身 — 🔶综合产物（组件已验证，组合为森林设计，无单一出处）

---

## 一、系统目标（荣总已确认的三层意图）

1. **表层**：从多轮对话中找出思维跳跃的地方，缩小"不知道的不知道"。
2. **真实目标**：不是治好跳跃（跳跃是跨领域工作的引擎），而是让盲区从模糊的自我感觉变成可观测的证据。已知盲区方位：目标、结果、落地维度。
3. **深层约束**：决定权永远在荣总手里。系统只制造盲区暴露的条件（预测、碰撞、惊讶），不下结论、不给建议。

## 二、共识铁律（不可违反）

1. **盲区是撞出来的，不是测出来的。** 任何声称能直接"检测出盲区"的产出都是违规。
2. **森林不产出结论**，只产出「盲区候选 + 暴露途径（什么行为可以证伪它）」。凡不能指定证伪途径的候选，不得呈现给荣总。
3. **确认权永远在荣总。** 季轨免疫地图第3栏（隐藏承诺）、第4栏（大假设）的产出必须标注"推断，待验证"，由荣总验证或否决。
4. **提醒≠建议。** 目标弱项提醒已授权，但只提醒，不带方案。
5. **数据规则**：荣总的原始对话数据、与AI交互数据不可篡改；外部数据和行为结果数据不可更改。预测必须从荣总嘴里出来，森林只记录，不代写预测。

## 三、双轨结构

### 日轨（实时，零成本，嵌在正常对话里）
- **预测登记**：对话中出现可验证判断时，森林提示"要不要登记"并代笔：预测 + 置信度% + 当下情绪状态，一句话。
- **优先登记短反馈周期预测**（如完播率、转化率），长反馈环判断不登记（Tetlock 局限：校准只对可解决问题有效）。
- **撞击标记**（与森林对话中，森林主动标记）：荣总打断/纠正森林、想纠正但忍住、预测落空。

### 触发轨（事件驱动，荣总30秒成本）
- **真人碰撞后**：一个勾 + 一句话回传（语音转文字亦可，格式不限，森林负责结构化）。
- **五类撞击信号**（任一发生即记一次撞击）：
  1. 被对方打断
  2. 解释欲上升
  3. 想纠正对方但忍住了
  4. 预测落空
  5. 身份介绍没起作用（专家身份壳失效）

### 季轨（预测≥10条或撞击≥20次触发，或每季度）
- 对"预测命中率最低的领域"和"撞击密度最高的话题"做四栏免疫地图：
  1. 改进目标 2. 反向行为 3. 隐藏竞争承诺（标注：推断） 4. 大假设（标注：推断）
- 大假设产出后，下一季所有碰撞实验（与AI碰撞+与真人碰撞）靶向该假设（safe-to-fail 实验）。

### 月度（预测≥10条才触发）
- 校准统计快照：命中率、按领域/情绪状态分桶的偏差模式。纯计算，无观点。

## 四、分工边界

| 环节 | 森林 | 荣总 |
|---|---|---|
| 预测登记 | 提示+代笔 | 预测本身必须从荣总嘴里出来 |
| 校准统计 | 全部 | 无 |
| 撞击日志（AI对话） | 主动标记 | 无 |
| 撞击日志（真人碰撞） | 结构化回传数据 | 当场一个勾+一句话 |
| 免疫地图 | 引导（第3/4栏标注推断） | 验证或否决 |
| 目标弱项提醒 | 执行（已授权） | 被提醒 |
| 真人碰撞 | 设计实验 | 全部执行 |

## 五、六类真人碰撞对象（异质性梯度排列）

| # | 类型 | 暴露什么盲区 | 设计原则 |
|---|---|---|---|
| 1 | 只问结果的生意人（销售/操盘手/小老板） | 目标-结果弱项 | 不接过程叙事，直接问"多少钱、什么时候交" |
| 2 | 单一领域20年深井专家 | 跳跃中哪些是天赋、哪些是逃避深度 | 用领域内绕不过的细节打断跳跃 |
| 3 | 00后重度用户 | 默认过时的假设 | 代际认知差 |
| 4 | 有权拒绝、不认识身份的人 | 专家身份壳外面的荣总 | 熟人反馈系统性失效 |
| 5 | 有战绩的反面阵营 | 最强信念的假设检验 | 真人反对者不按辩论规则来 |
| 6 | 年长10岁的同款理想主义者 | 时间轴碰撞（不是框架碰撞） | 10年后的可能分支 |

**特殊设计**：
- **花钱买被分析**：位置倒转，荣总作为来访者/被督者被分析（他已有心理督导体系，方向反过来用）。
- **每次碰撞三行协议**：撞前登记预测（"我预计对方会___，我预计我会___"）→ 撞中撞击信号打勾 → 撞后一句话回溯（"哪里和预测不符"）。

## 六、森林的角色与局限声明

**角色**：①证据保管人（跨会话持完整证据链，不疲劳，内心型议题第37次也不敷衍）②结构化引擎 ③碰撞对象之一。

**局限（必须持续声明）**：
1. 与荣总共享同一类认知框架——框架外的盲区森林连提问都构不成。
2. 荣总在AI对话中恒占结构权威位（甲方/训练者/纠正者）——AI对话数据系统性掩盖平等/弱势位置上的行为模式，**不能外推到与真人互动**。
3. 分析的是表达，不是认知。说出来的思维是思维的损耗版。
4. "只描述不下结论"的线在实践里划不住：描述即选择，观察渗透理论。缺席分析必须标注"相对于什么框架缺席"。

## 七、执行节奏

| 频率 | 动作 | 触发条件 |
|---|---|---|
| 实时 | 预测登记提示、撞击信号标记 | 每次对话内 |
| 事件驱动 | 真人碰撞回传 | 荣总带来 |
| 月度 | 校准统计快照 | 预测≥10条 |
| 季度 | 免疫地图+大假设+下季碰撞设计 | 撞击≥20条或季度到 |

**节奏原理**：高频浅记录+低频深加工——数据不够时强行出模式结论=巴纳姆陷阱（系统第一大死因：过早归纳）。撞击是随机事件故事件驱动。校准需样本量故月度以上。强制把深度时刻降解为数据点，防止系统退化为深度对话娱乐。

## 八、系统六大风险备忘（共识过程中识别，持续监控）

1. 假独立性：多代理同底模，交叉验证的置信度不可信
2. 巴纳姆伪洞察+被看见成瘾：内心型人格最易被"深刻感"俘获
3. 人格标签种子污染：内心型/目标弱项作为待审计假设，不作为前提
4. 跳跃病理化+观察者效应：撞击识别不得内化为表达自我审查
5. 表达≠认知的认识论鸿沟：恒定存在，只能显式承认
6. 系统过重→放弃：所有环节>30秒即违背设计

## 九、同构方案检索结论（2026-08-24）

英文市场相邻产品（Replika/Rosebud/Mindsera/Reflectly/Pi/BetterUp）全部为"镜子模式"（表达模式识别→反馈洞察感），无一家组合可证伪预测+大假设实验+真人碰撞设计。中文市场未检索（⚠️）。无先例=无前人踩坑经验，前几轮结构大概率要改，属预期内试错。
