## 网络代理与环境（2026-09-09 建立，2026-09-16 修正）
- 本机会话环境常带 `HTTP_PROXY/HTTPS_PROXY`（指向本机代理端口）。**端口每次会话可能不同，禁止在规则里写死具体值。**
- 症状：git 推 GitHub 报 `CONNECT tunnel failed 502` / `schannel: server abruptly closed`；curl 访问 localhost 报 502；jsdom 加载本地静态资源失败。重试无效。
- 解法：外部请求用 `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY <cmd>` 绕代理直连；本地地址用 `curl --noproxy '*'` 或 `no_proxy=localhost,127.0.0.1`。
- **端口获取方式（替代写死值）**：读环境变量 → 探测候选端口 → 直连，三级回退。工具见 `~/.workbuddy/tools/search_web.py`。
- GitHub 推送凭据模式：`git -c credential.helper= -c credential.helper=wincred push origin main`（绕开 PortableGit 的 helper-selector 卡顿）。
