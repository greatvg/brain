## 0. 总原则

两条"冻结"：

- **问题冻结的是"要回答什么"，不是"答案应该长什么样"**——问题定稿后，不许为了让某个答案显得成立而改问题。
- **事实代理冻结的是"怎么把事实搜全"，不是"哪些事实更合原有看法"**——搜事实的人只管搜全，不管合不合心意。
- **每个问题的"决定性"（对最终决策影响多大）在 0.6A 定稿时锁定**，搜索过程不得反向改优先级——"搜到的多"不等于"更重要"。
- **不过度外推（2026-09-18 v2.1 升格）**：案例证明案例；跨案例支持的是模式；模式不自动等于普遍规律。
- **存在性可审计 ≠ 忠实性可审计（2026-09-20 v2.2 新增总原则）**：留痕只能证明"某事发生过"，不能证明"某事做得对"。凡自检（自己查自己）只能覆盖存在性；忠实性必须由独立判定者覆盖——这是判据分级（2A.10）与红队必选（第 3 节）的总依据。

## 输出语言规范（一切给决策人的文档都适用，永久条款）

1. 禁止英文术语。实在必须保留的英文（网址、产品名、行业通名如 AI/VR/OTA），首次出现时括号加中文说明。
2. 晦涩行话一律改白话，或首次出现时给白话解释。新旧对照见下方术语表。
3. 编号系统（事实 F1、任务 T1、缺陷 I1、检索路线 QF-1、优先级 P0-P2 等）保留，但首次出现必须带中文名。

## 0.0 委托登记簿（v2.2 新增，防重复套利）

- **登记**：每次立项（0.1）前先查登记簿——同主体 / 同产品 / 同市场方向的先前委托必须列出。
- **重复委托规则**：与既往登记实质相似的委托（措辞微调也算），**强制引用上轮结论**并声明本轮差异点；上轮证据池默认沿用，不重搜。
- **例外口子**：允许"新证据出现"类重复委托——须引用旧登记 + 具体声明证据更新点（什么新事实使重查有必要），主代理核对属实才放行。
- **判据**：立项书附登记簿查询记录；重复委托有引用与差异声明；例外有证据更新点声明。
- （登记簿只约束系统内部——决策人到系统外另开一单可绕过，此局限写入 2A.11。）

## 0.1 立项书（主代理起草）

- 单栏任务定义区：决策问题（一句话）/ 证伪标准（含反向写法：什么证据能推翻它）/ 范围边界（地理/时间/对象/排除项）。
- 看法隔离：立项书写成"没有作者"的文本；决策人自己的原有看法不进会话，由决策人**在会话外自己记下来**（一句话看法+信心百分比）。**自留档落盘到固定位置（与立项书同目录）**——解释层输入以此为通道（v2.1 衔接）。
- 第 0 优先信源：先查内部资产（案例库/知识库/既有调研产出），再搜外部。

## 0.5 问题体检（独立校验代理）

- 知识边界（白名单）：不上网、不看内部资产、不引用案例；不得引入立项书之外的事实/案例/数字/具体实体（抽象框架和类别除外）；只允许做：定义分析、逻辑拆解、问题改写、结构操作。
- 六项固定检查：
  1. **决策对象检查**：列出"真正要做的决定"的所有候选（做产品？进市场？机制值不值？选哪种模式？换场景？……），说明每个候选会导向多不一样的搜索范围。
  2. **复合问题拆解**：一个问题里塞了几件事 → 拆开，每件事各配"什么证据能推翻"的判据。
  3. **暗藏结论检查**：逐词找问题表述里偷偷藏着的未验证判断。能检验的 → 降级成明面上的待验证子问题；不能检验的 → 删除，且禁止进搜索关键词。
  4. **证伪方式检查**：判据需要的证据，公开渠道能不能拿到？（"主因是需求侧"这种归因判断、复购/营收数字，搜事实的代理凭公开网页能不能判定？）判据是否需要"总数/比例"才有意义？（"≥2 个失败"在总数是 3 个还是 300 个时意义完全不同）判据需要的总数必须在这个问题的搜索范围内找得到，否则判据不可执行——改判据或扩范围。
  5. **相邻问题**（三个方向，各 1-3 个）：上游问题（更根本的条件，它不成立商业问题就不用谈）/ 下游问题（买家实际为什么掏钱——可能和立项书写的不一样）/ 横向问题（换变量：对象、场景、客户、价值链位置是不是选错了）。
  6. **付费理由分类清单**：4-6 类，类别之间分得开，但允许一个买家同时有多重理由（多标签）；标注哪些立项书已提、哪些没提。
- **付费理由不设限**：不许预设"买家买的是研究者认为的价值"；必须允许搜索后发现真实付费理由是另一种。
- **定义敏感性行（v2.2 新增，H 项）**：问题地图中每个含定义性选择的关键概念（市场边界 / "空白"的判定 / 对象范围 / 形态划分等），须附一行定义敏感性说明——换一个合理操作定义，问题的答案会不会变？**备选定义集提前锁定**：每个关键定义至少给 2 个合理操作定义，**必含一个对结论最不利的定义**（禁事后挑定义——若只有"对结论有利"的定义被检验，结论按"定义敏感未处理"降级）。
- 产出：决策对象候选 / 暗藏结论清单 / 拆解方案 / 证伪判据审查 / 三向相邻问题 / "并且-或者"问题地图草案 / 固定一节"我没把握的地方"（禁止假装确定）/ 定义敏感性行与备选定义集。

## 0.6 定稿（决策人两个动作）

- **0.6A 盲定稿**（看到自己原有看法之前）：选决策对象 / 定问题地图 / 定"并且-或者"关系与硬条件、软条件 / 定必查项 / 定优先级 / **定门槛的两个必答题**——①按什么单位计数（产品还是运营主体）②运营状态怎么算（运营中/暂停/已关停/改名换主体/不详；门槛按"连续运营"还是"累计运营"）。全部记录版本。
- **0.6B 原有看法对照**：打开会话外自留档，只做对照检查（一致/冲突/遗漏）。**冲突本身不构成修改理由**（冲突恰恰说明原有看法可能错，是高价值信息）；允许修改的只有三类结构性遗漏——决策对象漏了 / 必要决策变量漏了 / 逻辑依赖漏了——且必须记修改记录（为什么改）。
- **【问题冻结】**：地图定稿后，本轮调研内问题不许改；新发现的问题进未决清单。
- **决定性锁定**：每个节点"对决策影响多大"在 0.6A 定稿时标好；事实代理只标"缺失+能不能搜到"；主代理核验时**按地图**标决定性；搜索中发现的新缺口一律进未决清单，不许反过来调搜索优先级。
- 三种状态：**正常推进 / 证据不足（问题成立，但公开渠道找不到足够证据）/ 问题作废（问题本身没法稳定定义，或判据没法操作化）**。判"问题作废"的决定权在决策人，且必须先处于"证据不足"状态、**提前锁定的检索路线清单全部跑完**（申报时附清单打勾记录）。事实代理只有申报权，没有决定权。

## 转写层（主代理把问题地图改写成搜索任务书）

- 转写原则：**0~0.6 可以复杂，1.0 必须简单**。"并且/或者"、硬软条件、触发条件、优先级，全部在转写时消化掉；事实代理拿到的扁平清单里没有逻辑判断、没有打分任务。
- **转写只消化不新增**：任务书里凡转写层新加的实质内容（门槛数值/时间窗改动/优先级安排）必须标【转写新增】并回头让决策人在 0.6A 确认——实测中"值得进入的门槛"就是越权实例。
- **立项书条目编号**：转写第一步，把立项书里的每一条要求（决策问题/证伪标准/范围边界每一项/排除项/对照要求）逐条摘出来编号（条目1、条目2……）；任务书每一项都标注它来自哪条条目。
- 任务书内容：对象定义/排除项/检索三向（正向+反向+用户声音）/优先级（P0 最优先、P1 次之、P2 有余力再查，P2 出现独立证据才升级）/分母要求/产出固定格式/预算与停止条件。
- **硬条件**：触发条件必须在 0.6A 全部预先写死在地图上；事实代理只有执行权没有解释权，不许中途发明停止条件。
- **必查项**：约束"搜没搜到"不约束"挖多深"——最低交付=摸一级（确认有没有）+状态标注（没到结论级的分支标"证据不足（摸一级）"）；要不要降级在 0.6A 定。
- **"或者"型分支的预算**：每条路径先给最低探索额度，之后按"哪条有新信息"分配深挖预算——防止"网上好搜的饿死不好搜的"（网上曝光多≠现实中重要）。
- **搜索预算与深度显式数字化并冻结（v2.2 新增，A 项配套）**：任务书必须写明每条检索路线的搜索深度档（摸一级 / 摸二级 / 结论级）与投入上限（路线数 / 轮次）——**把管家在"翻译"时的自由裁量压成留痕参数**；冻结后改动 = 违规，须走决策人确认。
- **提前锁定的检索路线清单**：转写时产出——关键词族 / 信源类型 / 语言 / 时间窗，作为事实代理停止条件的机械验收依据（见执行规则第 9 条）。
- **【转写警报区】**（决策人过目任务书时**只看警报区**）。一套机制管三类毛病：
  - **漏抄**：编号后没有任何任务引用的立项书条目（集合运算机械检出）——防悄悄丢要求。
  - **改义**：①高危条目（原文含"分裂/条件"信号词——词表提前锁定，如：均需/两种/各/分别/且/或/不分/除外/仅/必须覆盖）没有附"保真记录"（保真记录=原文摘录+任务书落点编号+保留条件，三行以内）；②单个任务项挂了超过 3 条条目编号（防"万能条目"假覆盖——比如"全面研究该方向【条目1~8】"其实什么都没写出来）。
  - **空转**：任务项没落到能搜的字段（数字/日期/状态枚举之一）——比如"调查儿童留存"没说留存怎么算，代理只能搜到泛泛评论。
  - **警报区为空才许派事实代理**；警报条目由决策人裁决（补转写/改条目/明确放弃并记录）。
  - **警报区原始证据必须落盘**：漏抄的集合运算结果行、改义的保真记录三行、空转的判定行，作为警报区交付物的一部分（盲跑重测发现的记录缺口，防止"事后补记"与"真拦截"无法区分）。
  - **三检忠实性移交独立闸门（v2.2 新增，A 项）**：转写自查三检（漏抄/改义/空转）属于"存在性可查、忠实性不可自查"——警报区为空的结果必须由**独立闸门代理**（满足独立性最低标准，见 2A.10）按模板化规则复核一遍翻译是否忠实，复核记录落盘；管家自查不再作为唯一关卡。

## 1 事实收集（独立事实代理）

- **执行规则（≤9 条；超过 9 条=转写失败的信号，回转写层重做，不许硬塞）**：
  1. 只找事实（发生了什么），不做因果解释；别人的解释原句摘录进暂存区，不采信。
  2. 只按任务书执行，不自行推理任务之外的依赖关系。
  3. 按 P0→P1→P2 顺序执行；P2 出现独立证据才升级。
  4. 每条事实带网址+日期+数字口径（数字怎么统计的）；证据三级：强（财报/官方披露/法院文书）/ 中（平台可查数据）/ 弱（自称/转述）；**转手超过 2 道（如百科转引部委、部委又转引自报告）降为弱**。
  5. 独立信源计数：同一篇文章的转载记 1 个；引用同一出处的只算原始出处；只数能追溯到一手来源的。
  6. 没找到 ≠ 不存在。格式：`检索事实：截至[日期]，按既定检索范围与关键词[X]，未检出符合条件的[目标]`；另记一行 `未检出-[编号]|目标|范围与关键词|结果|日期`。
  7. 对照案例可比性优先，宁缺毋滥；可比性分三档（可比/部分可比/不可比，部分可比降权标注）；禁止为凑满"≥N 个"放宽可比性；**"≥N"是覆盖目标，不是真实性门槛**。检索动作必须做，产出如实记录（对照矩阵允许 1 比 0、2 比 1）。
  8. 分母纪律：记"≥N 个失败/成功"必须同时记总数+总数怎么定义+覆盖时间；总数不知道就标"分母缺失"。
  9. 停止规则：连续 2 轮只产生已记录事实的重复证明（没有新事实/新来源/新维度）→ 触发停止判定。**停止前逐项打勾提前锁定的检索路线清单，有没跑的项不许停**（换路径跑完再判）；全部跑完才能停，并输出停止声明（附清单打勾记录；停止=提前锁定的范围搜完了，≠事情查清了）。
- **检索三向必须各有动作**：正向（活着的产品+定价+销量）/ 反向（关停/转型/停更/纠纷）/ 用户声音（能追溯的公开渠道原句，多标签挂分类清单，禁止填"主导理由"；原句须标注和对象定义的相关性，不是本对象的原句单独归档不计入；**渠道类型不符时标注"经媒体转述"**）。
- **时间线状态节点**（2026-09-18 决策人修订）：平行时间线必须同时覆盖两类节点——正向（上线/改版/融资/扩张）与**负向（下架/停止更新/暂停运营/关停/转型/改名换主体）**。负向节点必须带时间点（至少精确到月；查不到就记未检出记录并标"时间不详"）；「运营中」的产品必须记录可追溯的起始运营时间——这是"连续运营 ≥N 年"门槛的唯一判定依据。只记正向不记负向 = 时间线覆盖不合格，主代理核验按缺失处理（幸存者偏差防线：产品何时死与何时生同样是证据）。
- **用户声音证据等级封顶**（2026-09-18 决策人修订）：一切用户声音（评论/帖子/访谈引述）默认封顶"弱"——非系统抽样、自选择偏差（极端体验者更愿意发声）、身份不可验。只可用于①假设生成与竞争假设排队②解释层线索；**禁止**作为门槛判定、最终裁决的独立依据；引用时必带"非系统抽样"标注。（解释层场景的分层细则见 2A 章节第 5 节——细化本条，不修改本条正文。）
- **10 个方面的事实覆盖**：背景/时间线/行动/结果/人物/资源/外部环境/产品业务变化/用户反馈/异常事件。缺的方面由事实代理标"缺失+能不能搜到"，主代理核验时按地图标决定性。**任务书里对象定义含形态排除（如"仅在线、排除线下"）时，事实表必须强制加"形态"列**。
- **枚举类任务的窗外声明**：纳入时间窗之外的案例必须声明理由（盲跑重测新增细则）。
- **【局限声明职责（收窄版）】**：事实报告"覆盖局限"声明里，凡属于**检索层**的缺失（搜了没搜到/渠道缺/语言缺）条目，自动列入未决问题清单；转写层丢失和改义的防线在转写警报区（事实代理根本不知道有条目被丢了，无从申报）。局限声明不许写成免责声明。
- **四件套固定交付格式（v2.1 衔接）**：立项书 / 问题地图（0.6 定稿版）/ 搜索任务书 / 事实报告，全部落盘独立文件 + 固定结构——解释层输入以此为唯一通道。

## 2A 因果解释层（第 2 阶段，v2.1 并入定稿版；v2.2 修订）

> 章节来源：设计三轮收敛 + 首件实测 + 外部交付物设计与判定纪律修订 + 判据分级补强（章节定稿版 v1.3，2026-09-18）+ 外部红队批判裁定 12 项修订（v2.2，2026-09-20）。工程层产物（假设矩阵、反证签名、规则执行总账）照跑照存档，属内部质检记录，不进交付物正文。

### 2A.0 交付物形态（最高优先条款）

**解释层交付物 = 决策结果包**，只回答一个问题：**基于目前证据，今天应如何理解这个决策。**

**首屏（一页铁律——固定 5 行，独立成立）**：

> **证据截止日：YYYY-MM-DD（证据覆盖窗口：YYYY–YYYY）**——判断的时效标注，必填。决策人只读首屏就能行动，正文按需读：

| 行 | 内容 |
|---|---|
| 1 | 一句话结论：判断 + 性质（支持 / 部分支持 / 不支持 / 无法判断）+ 强度（高 / 中 / 低——按二轴四格规则矩阵机械推导，见 2A.5；**性质=无法判断时强度栏写「—」，禁硬填凑格式**） |
| 2 | 最关键依据 2-4 条（判断与事实分开标——判断 ≠ 事实，挂钩既有「严格事实/推断分离」标注） |
| 3 | 当前保留的机制一句话（+被排除 / 受挑战的） |
| 4 | 最大不确定性 1-2 条 |
| 5 | 下一步最该验证的一个问题 + 大概验证成本 |

**正文六节**：

1. **决策拆解**：子问题 × 当前判断 × 关键依据 × 子问题间逻辑关系——逐个呈现，不合并成一个笼统总判断；
2. **因果解释摘要**：核心因果命题 × 四态 × 最大不确定性——**必须是内部四态矩阵的投影摘要，不得另画一版**（防两版漂移）；
3. **竞争解释结构**：为什么当前保留这个解释、不保留其他——呈现证据结构差异，不打总分；含发现池新候选及其状态；
4. **边界条件**：成立条件 / 证据失效或不适用的场景 / 尚未知晓的条件 + **判断翻转条件（固定小节）**：出现什么证据当前判断上调、出现什么证据下调或作废——与「最大不确定性」不是一回事，把一次性报告变成可持续更新的判断系统；
5. **决策含义**：A 支持了什么（对照立项书预期=0.6A）/ B 推翻了什么 / C 决策空间收窄了什么 + 下一步验证什么（每项标验证成本；**当唯一有效验证=行动本身时（如上线测转化），写「行动即实验」，不再列检索路线**）+ **不做什么**（当前证据不支持投入的方向+理由——省下的投入是解释层的直接价值）；
6. **不能下的结论**：本次研究明确不能得出的结论（例：「案例少 ≠ 家庭需求不存在」）+（条件可选）反事实——仅当存在自然对照（时间断点 / 干预前后结构）时填写，否则明示「无对照数据，反事实无法评估」。

**交付质检清单（主代理出厂核对用，8 条全过才算出厂；不进正文）**：①决策相关性 ②事实-解释分离 ③证据可追溯（重大结论能追到证据编号）④竞争解释完整（含未选择替代解释的理由）⑤不确定性显式化（禁把无法确认补成结论）⑥边界明确 ⑦不过度外推 ⑧能改变决策（对照 0.6A 预期）。

- 固定字段按语言规范中文化：决策结论 / 决策拆解 / 因果解释摘要 / 边界条件 / 反事实与不确定性 / 决策含义 / 不能下的结论。
- **判据**：决策人读完首屏能直接列出「下一步做什么 / 不做什么」；正文六节齐全，且第 2 节与内部矩阵逐条一致。

### 2A.1 输入契约（两次开封）

- **第一次开封**（列假设阶段）输入：立项书 + 问题地图（0.6 定稿版）+ 决策人看法。
- **第二次开封**（做矩阵阶段）输入：事实报告 + 未决清单 + 检索完成度声明。
- 两批输入之间，**假设清单锁定**（防"看着答案编问题"——与 0.6A 盲定稿同构）。
- **三道墙**（解释代理全程不看）：①事实代理的搜索路径（关键词 / 渠道顺序 / 过程叙述）②主代理核验的倾向性意见③未检出记录的关键词级细节（只给每条路线跑完 / 未跑完 + 一句话覆盖范围）。
- **独立性执行细则**：解释代理须用**独立会话 / 独立代理**执行，输入仅限两批文件——单会话「纸面模拟」两次开封不成立；凡模拟产出一律标注「纸面模拟」并按降级证据对待。**机械保证**：时间戳链自动比对——假设清单落盘 → 签名落盘 → 事实开封，三个文件时间戳必须递增，不递增=流程拒绝执行。
- **判据**：解释代理输出中不出现任何搜索过程信息；两次开封的输入清单有落盘记录；执行会话独立或已标注模拟；时间戳链比对通过（留痕）。

### 2A.2 假设清单（三源混编 + 匿名）

- **三源**：①决策人看法 ②0.5 相邻问题推导（上游 / 下游 / 横向各至少一个）③用户声音生成的假设（按分层规则标级，见 2A.5）。**源不适用时显式标注「不适用 + 原因」，禁止硬凑**（如 B2B 数据类问题天然无用户声音源）。
- **覆盖五形态**：X 导致 Y ／ 零假设（X 不导致 Y）／ 替代机制（真因是 Z）／ 条件性（X 只在某些条件下导致 Y）／ 相关非因果（X、Y 只是伴生）。
- **匿名混编**：编号 H1…Hn，不标哪条是决策人看法（防权威位偏袒）；矩阵完成后主代理解密来源，做**偏向检查**（矩阵是否系统性轻判某条假设的矛盾证据——偏向检查由独立闸门代理执行，见 2A.10）。
- 锁定后不得增删；新解释走发现变量池 → 下一轮。
- **判据**：假设清单带三源覆盖核对表（不适用源带原因）；解密对照记录存在。

### 2A.3 两张锁定表（凡影响结论的结构，看到结果之前定）

- **候选区分变量表（提前锁定）**：哪些维度的差异**允许**用来解释结果差异（渠道 / 定价 / 时机 / 团队 / 形态……），加一列"来源：提前锁定 / 发现"。
- **案例配对条件表**：同景对照的"相似"按哪些维度逐项判定相同 / 不同——机械标注，禁凭印象。
- **时序规则**：配对条件默认只能用"干预前"变量——受 X 影响的变量拿来做匹配，等于强制"X 的结果相同"，把要检验的因果路径消掉。每个变量标时序位置（干预前 / 干预后 / 不明）：干预后禁用，不明降级为部分可比。
- **发现变量池**：搜索中发现清单外新变量 → 登记排队**下一轮**，不当轮生效；当前轮结论只许声明"发现池有未检验候选，无法排除"。一句话：**允许发现新变量，不允许偷渡新变量。**
- **判据**：两张表在假设清单锁定前落盘；解释结论引用表外变量 = 违规（只能走发现池）。

### 2A.4 机制拆解与检验强度对称

- **拆解粒度**：每个进矩阵的假设拆机制链（X→M1→M2→Y），按**最小可检验粒度**拆——每条因果边都能单独提出证据问题；**不按段数硬对齐**。
- **路线结构对称**：每个假设的支持路线 ≥N、反证路线 ≥N、每条因果边 ≥1 条关系证据路线（**结构配额相同**）；停止规则统一（连续 2 轮无新事实 + 路线打勾完）+ **「数据源不存在」分支**：候选路线全部执行 + 关键数据源确认在公开渠道不存在 → 停止并明示，**不算未完成**，禁止死循环硬搜。**不搞绝对条数对齐**。
- **机制图冻结**：假设进正式矩阵后，机制图版本冻结。**补证据可以**（给已有节点 / 边找证据），**改结构不行**（加新节点 / 新边 = 形成新假设版本）。
- **判据**：每个假设的机制图有版本号；每条边有对应检索路线编号；冻结后无结构改动记录；停止时有终止原因（规则触发 / 数据源不存在）。

### 2A.5 证据判定纪律

- **跨案例比较的定位**：同景对照 / 跨域对照默认只产出"候选因果变量"，不单独确认因果；有额外识别设计的比较（自然实验 / 明确时间断点 / 干预前后对照）由解释代理单独标记证据等级，可升级为因果证据的一部分。**跨案例对比是假设生成器，机制链检验才是假设检验器。**
- **四态标注（互斥）**：**直接支持 / 间接一致 / 矛盾 / 证据不足**——每条证据标且只标一个状态。「间接一致」= 方向一致的弱关系证据；「直接支持」= 有**识别设计**（自然实验 / 时间断点 / 干预前后对照）的关系证据——全观察性证据的机制链最多标「间接一致」。方向一致 ≠ 支持；「直接支持」长期为空也是诚实。
- **强度推导规则矩阵（二轴四格，替代简单矛盾计数）**：矛盾证据按两轴定位——**来源独立性**（独立多源 / 单一来源 / 用户声音）× **直接性**（直接观察事实 / 转述或推断）——四格各对应强度档位。「一条强矛盾 > 十条一致」中的「强」按本矩阵判定。**禁五维以上评分体系。**
- **机制支持 ≠ 因果识别**：机制链每条边都有证据 ≠ 因果成立——全观察性资料下，共同原因 W 同时影响 X / M / Y 的可能性无法排除；只有识别设计才能产生「直接支持」。**禁句：「机制链完整，因此 X 导致 Y。」**
- **两区分**：节点证据（M 存在）≠ 边证据（X 影响 M）；无证据 ≠ 反证——证据缺失 → 机制不完整（降级不淘汰）；直接矛盾 → 机制受挑战；强反证 → 可淘汰。
- **淘汰权分工**：强反证由解释代理**判定并执行矩阵层面淘汰**（标注「强反证淘汰 + 证据编号」）——证据判断按预设标准机械化；决策人保留**复核权**（可质疑证据标准执行是否有误）但**无偏好否决权**；是否因此改变业务决策，由决策人在「决策含义」层完整决定。
- **断链段禁止补链词**：「显然 / 必然 / 理所应当」出现在证据不足的边上 = 违规。
- **矛盾优先**：一条强矛盾 > 十条一致——状态比较按矛盾的质量与计数，不按一致计数。
- **用户声音分层（细化第 1 节封顶条款、不改其正文）**：用户声音分两层——①观点 / 态度（最弱，只能当线索）②当事人自述的具体行为事实（直接性采信，可作**机制存在性证据**，但外推范围锁死在个体层）。**外推封顶**：任何用户声音禁作总体规律证据、禁作门槛判定依据——**证据强度与外推范围分开**。
- **零鉴别力事实明示**：对全部假设都一致的证据，明示"该事实不区分任何假设"，禁计入任何支持栏，单独归档。
- **判据**：矩阵每格有四态标注（互斥、单选）+ 证据编号；矛盾证据有二轴定位；零鉴别力证据有明示行；淘汰假设有证据编号与复核记录位。

### 2A.6 反证从预测推导（反证签名）

- **三层推导**：假设 → 可观察预测（若 H 为真，应该观察到什么）→ 反证签名（什么事实出现 = H 受创）→ 检索路线。搜的是"预测的反面事实"，不是"反方观点"。
- **签名同批锁定**：反证签名与假设清单同批锁定——设计签名时不得接触事实报告正文。
- **签名挂靠**：反证路线必须挂靠反证签名编号；**编号字段非空=放行前置条件，字段为空流程拒绝执行**（机械保证）。
- **辅助假设预注册（v2.2 新增，E 项）**：每条反证签名必须附「本签名依赖的辅助假设清单」（工具可用性 / 定义口径 / 渠道覆盖等）。**矛盾出现后，只许用清单内条目辩护**（如"渠道 X 未覆盖所以没看到"）；事后新增清单外的"场景错位 / 测量有误"类辩护 = 违规——把无限辩护压成有限辩护，封住事后救援通道。
- **反对冲检查（v2.2 新增，E 项配套）**：独立闸门代理复核签名时加一项——**签名不得同时兼容正反两种结果**（预测写得覆盖所有情况 = 永不被强反证的高明对冲），命中即退回改写。
- **判据**：每条反证路线有签名编号；签名锁定时间戳早于事实开封时间戳；签名附辅助假设清单；闸门复核含反对冲项。

### 2A.7 解释层驱动的第二轮检索

- 解释代理不上网（知识边界白名单：允许抽象机制知识如"沉没成本 / 渠道依赖 / 幸存者偏差"等通用模型，**但仅限下述用途**；**禁止**引用四件套之外的具体案例 / 公司 / 数字——证据池封闭）。
- **机制知识防污染**：通用机制知识只可用于**生成与命名机制假设**；不得作为本案例的证据、不得提高本案例任何边的证据状态、不得作为四态标注依据。
- 四路搜索（支持 / 反证 / 替代解释 / 机制证据）由解释代理设计成**第二轮检索任务书** → 事实代理执行 → 解释代理消费结果。
- **补证搜索最多一轮**：该轮发现的新假设 / 新变量只登记进发现池与未决清单，进**下一研究轮**，不触发第三轮。
- **检索投入列（v2.2 新增，F 项）**：矩阵与结果包中，每条假设必须附一列"已投入检索投入"（已执行的路线数 / 轮次）——**让"谁被搜得多"可见**：证据不足的标签必须能区分"搜了没有"和"搜了没找到"；没投入过检索的假设不得显示为"间接一致"（无知不得读成支持）。
- **基率分离供给（v2.2 新增，F 项配套）**：涉及"失败/成功比例"类判断时，分母（基率）数据由独立检索供给，不与假设证据混在同一池——防止用有利口径的分母美化比例。**基率请求书模板化提前锁定**：口径 / 分母定义 / 时间窗在检索前写死，解释代理不得定向索取有利口径的基率。
- 第二轮任务书继承转写警报区检查（空转等）+ 未检出格式 + 停止规则。
- **反证路线关键词由独立闸门代理复核**（见 2A.10）——防"假反证"：搜注定搜不到的稻草人版本，然后宣布"反证未检出，假设存活"。
- **"没搜到"永远不能当"不存在"用。**
- **判据**：第二轮任务书过警报区；未检出记录按格式落盘；补证轮次 ≤1 且新发现全部登记、未当轮生效；矩阵附检索投入列；基率请求书有提前锁定记录。

### 2A.8 输出纪律（证据状态比较，无胜出）

- **禁「X 得到证实」类表述**。只有三种合法句子：①"H1 未解决矛盾最少且关键边证据最全" ②"H3 按证据标准已遭强反证（矩阵层面淘汰，复核权在决策人）" ③"H2 与 H1 证据状态不足以区分，区分它们需要 X"。逐假设列**证据状态**（证据较多 / 存在 N 条未解决矛盾 / 关键边缺证据 / 存在直接矛盾），不包装成「H1 获胜」。
- **两轴排序（v2.2 新增，G 项——替代单轴排序）**：假设排序按两轴独立呈现、**不合并成单一排名**——**轴一**：未解决矛盾的最高强度档（按 2A.5 二轴四格）；**轴二**：证据密度门槛（该假设获得了多少条来自独立来源的直接观察）。**未达轴二门槛（证据密度不足）的假设不参与排序**，标「未达可比较门槛」——不许因"零矛盾"登顶（无知不得读成支持，防奖励空泛未被检验的假设）。
- **结论形态条件化**：「在 A/B/C 条件下，X 对 Y 有较强证据；在 D/E 条件下证据不足或出现反例；当前仍无法排除 Z 的替代解释」——禁止裸的"X 导致 Y"。
- **句式白名单（v2.2 新增，J 项——禁句黑名单升级）**：词法过滤可被同义改写绕过，故结论句升级为**白名单制**——结论句必须匹配三种合法句式模板之一（同三种合法句子），**模板外 = 出厂失败**；禁句扫描保留作为辅助（抓不留心的过度声明）。
- **反叙事检查**：输出强制含"与流畅叙事冲突的细节"一节——故事越流畅越要找茬。
- **多因结论**：允许，但各因须标"必要 / 加速"。
- **比较性评估归属**：由解释代理产出（不打分，明示三维度：支持证据强度 / 反证强度 / 机制完整度）；主代理只做机械核对，**不下因果评语**（批判者必须独立进程）。
- **判据**：结果包首屏+六节齐全（第 2 节与内部矩阵逐条一致）；结论句全部命中白名单模板；排序呈两轴；未达门槛假设有标注；反叙事检查存在。

### 2A.10 判据分级（纪律的机械保证）

**原则：纪律不能只靠口头，每条判据必须落到两级载体之一——能机器查的全部字段化留痕，机器查不了的移交独立判定者。主代理不再自审判定类事项（「批判者必须独立进程」的落实）。**

**独立性最低标准（v2.2 新增，批判 14 的可操作部分）**：凡称"独立闸门"者，必须同时满足三条（缺一不得称独立）——
1. **闸门规则锁定**：判定用的提示词 / 模板 / 规则提前锁定落盘，管家与决策人均**不可单方面改写**（改动须走决策人显式确认并留版本记录）；
2. **判定模板化**：只用可机械核对的模板化规则判定，不使用自由裁量；
3. **分离留痕**：闸门的会话 / 代理标识落盘，供核对确实独立执行（v2.2 新增，I 项——角色分离本身是被核查对象，主代理机械核对会话标识）。
（诚实声明：同一部署方、同一激励结构下的角色分身，其"独立"仍是模拟的——残余风险写入 2A.11，靠哨兵种植案 + 红队 + 决策人抽检承接。）

**第一级：机械检查（流程内自动执行，留痕可查）**：

| # | 检查项 | 载体 | 拒绝放行条件 |
|---|---|---|---|
| 1 | 时间戳链 | 假设清单 → 签名 → 事实开封三个文件时间戳 | 不递增 = 拒绝执行 |
| 2 | 编号非空 | 反证路线 F 编号 / 每条边路线编号 / 机制图版本号 | 字段为空 = 拒绝放行 |
| 3 | 计数封顶 | 补证轮次计数器 | >1 = 自动截断并登记 |
| 4 | 禁句匹配 | 交付物字符串扫描（2A.8 四类禁句）+ 句式白名单核对 | 命中禁句或结论句脱模板 = 不出厂 |
| 5 | 出厂清单 | 8 条质检逐项打勾留痕 | 缺项 = 不出厂 |
| 6 | 分离留痕核对 | 各角色会话 / 代理标识（v2.2 新增） | 标识缺失 = 视同未独立执行 |

**第二级：判定检查（机械不了的，移交独立判定者）**：

- **偏向检查**（矩阵是否系统性轻判决策人假设）→ **独立闸门代理**执行，主代理只移交材料；
- **解密表输出剥离（v2.2 新增，C 项）**：偏向检查闸门在隔离上下文内**照常持解密表**（保证判定质量），但其输出（判定书 / 退回清单）**剥离"与决策人假设的关联"后**才流转给下游——防下游（解释代理 / 主代理）从退回意见反推哪条是决策人的假设；
- **反证签名稻草人复核**（关键词是否注定搜不到）+ **反对冲检查**（签名是否兼容正反结果）→ **独立闸门代理**复核；
- **转写三检忠实性复核**（v2.2 新增，A 项——见转写层节）：警报区为空的结论由独立闸门按模板化规则复核；
- **仲裁规则（v2.2 新增，B 项——终裁子条款被驳回重设）**：两个判定者意见冲突时——**主规则：冲突自动取更严格结果**（机械降级证据状态，零裁量，无后门）；机械规则确实无法适用的**程序性争议**（如"该争议是否属于机械规则覆盖范围"本身有争议），交独立仲裁人裁决——仲裁人须满足独立性最低标准，且与双方猜想无利益关系。**决策人只出现在质量控制下游（看最终结果包），不进质量控制内部**（复核权在下游行使，不是仲裁权）。
- **淘汰复核权** → 决策人（可质疑标准执行，无偏好否决权）。
- **看门人统计与哨兵种植案（v2.2 新增，B 项配套）**：纪委判定书（拦截 / 退回记录）**全部落盘**供统计；**率本身测不出偏置方向**（50% 可能是严格也可能是对一切过度挑刺，2% 可能是宽松也可能是已被捕获）——故定期混入**已知答案的测试案**（已知稻草人签名 / 已知明确矛盾）：哨兵被放过 = 看门人失能，哨兵检出率 = 看门人真实能力的机械测量。这是协议哨兵机制第一次反身应用到看门人身上。

- **闸门通路**：独立闸门沿用既有 critic 子代理封装（gate-checker 类独立进程），不新造机构；
- **最后一道兜底**：决策人抽检 + 实战暴露 + 红队必选（第 3 节）——机制的价值是让抽查**有处可查**（时间戳 / 编号 / 计数全留痕），不是依赖 AI 自觉；
- **判据**：每份交付物附机械检查留痕记录（6 项逐项结果）；判定类检查有独立代理执行记录（含会话标识）；哨兵测试案有执行记录；两项缺一 = 视同未质检。

### 2A.11 已知局限声明（v2.2 新增，K 项——元诚实条款）

**以下缺口是本协议当前防不住的，写明而非假装封闭——防止把「已打补丁」误当「已安全」（决策人原话，2026-09-20）。**

1. **事后善意解读不可审计**：时间戳证明字符串当时存在，不证明此刻给出的解释就是当时本意——"歧义解读"是看起来完全正当的作弊路径，无法证明意图。只能收窄（辅助假设预注册、句式白名单）+ 抽检。
2. **同一主体分身**：管家、纪委、调查员、分析师若共享同一部署方与激励结构，对抗性是模拟的、不是真实的。角色立场分化 + 独立性最低标准 + 哨兵种植案降低风险，但无法根治。
3. **意图不可证明**：所有纪律防的都是"行为"，防不了"心思"——熟练的执行者可以在规则内实现系统性偏向。
4. **系统外委托绕过**：委托登记簿只约束系统内部——决策人到系统外另开一单（换措辞、换工具、自己搜），登记簿与重复委托规则全部失效。
5. **定义洗白的残余**：定义敏感性条款（0.5）收窄但不消灭"价值判断包装成事实"的通道——备选定义集是人工选的，选定义集的人本身可以是偏置源。
6. **意识到的攻击面剩余**：管家翻译已加闸门复核与预算冻结，但"用什么语料训练、给闸门什么上下文"等更隐蔽的通道未逐一枚举——红队（第 3 节）按全链路攻击持续探测。

**本节由决策人维护：实战中发现新的"防不住"，追加条目；发现某条已有解法，移出并注明条款号。**

## 3 红队（v2.2 升为必选——原"未设计"状态废除）

- **地位**：不再是预留阶段——上述全部残余缺口（管家裁量、纪委双向偏置、同一主体分身、事后解读）的唯一系统性承接者。
- **触发**：全流程级调研（第 3 节分级）出厂前必过红队；触发级与常载级按需。
- **攻击范围 = 全链路**（v2.2 决策人修正，不能只攻击分析师结论）：①管家翻译（任务书是否系统性引导）②纪委裁量（判定是否有双重标准、是否被捕获）③搜索预算分配（哪条假设被多搜 / 少搜）④隔离边界（信息流是否真的被墙住）⑤分析师结论（证据状态比较是否站得住）。
- **输入**：结论 + 关键证据 + 事实表 + 全链路流程记录（任务书 / 警报区 / 判定书 / 时间戳留痕）；不看决策人看法和推理过程。
- **产出**：攻击报告（逐环节列出攻击点 + 是否得手 + 修复建议），主代理不得自辩，修复项进未决清单或 v2.3 增量。
- **判据**：全流程级交付缺红队报告 = 未质检；红队报告只攻击单环节 = 不合格，退回补全链路。

## 需求侧分层（规则按需承担）

### 触发边界（简单搜索 vs 全流程协议，2026-09-18 决策人修订）

- **默认 = 简单搜索**：直接搜、直接答（带来源链接），只执行常载级 7 条；不立项、不体检、不建矩阵。
- **升级触发**（满足任一，主代理必须显式提议"跑协议"，决策人确认后才启动）：①问题指向"做/不做/投多少"的决策（信号词：立项/赛道/值得吗/有没有发展空间/该不该/做不做）；②决策人点名"跑协议/深度调研/系统调研"。
- **强制降级保险丝**：决策人说"简单搜索"→ 一律按简单搜索执行，不得自行升级（哪怕问题看起来像调研）。
- **一句话判据**：不按"商业/非商业"分，按"结果是否用来做花真金白银的决定"分——查资料/确认事实/学概念/找工具 = 简单；立项/投入/赛道 = 协议。判据与内容领域无关，与用途有关（查"明朝海禁"是历史问题，但若用来决定投资方向就是决策搜索）。

- **常载级**（一切搜索，含日常快查）：看法隔离 / 双向检索 / 只记事实不记解释 / 未检出格式 / "≥N"是覆盖不是门槛 / 停止规则 / 独立信源计数。
- **触发级**（满足条件才生效）：未检出记录全文（未检出将作解释层关键输入时）/ 分母纪律（失败计数用于证伪时）/ 树外探查（≥4 轮检索时）/ 同景·跨域对照矩阵（涉因果成败判断时）/ 可比性三档（建矩阵时）。
- **全流程级**（结论投入真金白银的大决策）：0.0 委托登记簿 / 0.5 / 0.6A / 0.6B / 三状态 / 代理分工 / 转写警报区（含独立闸门复核）/ 检索路线提前锁定 / 2A 解释层 / **红队必选**。

## 验收判据（质量控制信号）

- 要给事实代理解释太多规则 = 转写失败，回 0.6 重做任务书。
- 执行规则超过 9 条 = 转写失败。
- 警报区没清空就派代理 = 违规；警报区为空但无独立闸门复核记录 = 违规（v2.2）。
- 事实报告局限声明出现检索层"未覆盖 X"却没有对应的未决清单项 = 违反局限声明职责。
- 好的问题地图能把复杂的决策逻辑压缩成简单的搜索任务；压缩不了 = 上层没转写好。
- 解释层交付物缺机械检查留痕或独立代理判定记录 = 视同未质检，不得交付。
- 全流程级调研缺红队报告或红队只攻击单环节 = 未质检（v2.2）。
- 结论句脱句式白名单模板 / 未达证据密度门槛的假设参与排序 = 出厂失败（v2.2）。
