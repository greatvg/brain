> 版本 v2.0（定稿），2026-09-18 荣总指令写入。draft5 = draft4 + 决策人三条修订：①时间线强制覆盖负向节点（下架/暂停/关停须带时间）②用户声音证据等级封顶"弱"③新增"触发边界"（简单搜索与全流程协议的机械分流）。修订链：draft2（红队审查对象）→ 红队 20 条发现 → 外部两轮意见 → draft3 → 盲跑重测 10/10 拦截 → draft4 白话版 → draft5 → 定稿。v1.0 原文见本仓库 git 历史（SOUL.md 旧段）。

## 0. 总原则

两条"冻结"：

- **问题冻结的是"要回答什么"，不是"答案应该长什么样"**——问题定稿后，不许为了让某个答案显得成立而改问题。
- **事实代理冻结的是"怎么把事实搜全"，不是"哪些事实更合原有看法"**——搜事实的人只管搜全，不管合不合心意。
- **每个问题的"决定性"（对最终决策影响多大）在 0.6A 定稿时锁定**，搜索过程不得反向改优先级——"搜到的多"不等于"更重要"。

## 输出语言规范（一切给决策人的文档都适用，永久条款）

1. 禁止英文术语。实在必须保留的英文（网址、产品名、行业通名如 AI/VR/OTA），首次出现时括号加中文说明。
2. 晦涩行话一律改白话，或首次出现时给白话解释。新旧对照见下方术语表。
3. 编号系统（事实 F1、任务 T1、缺陷 I1、检索路线 QF-1、优先级 P0-P2 等）保留，但首次出现必须带中文名。

## 0.1 立项书（主代理起草）

- 单栏任务定义区：决策问题（一句话）/ 证伪标准（含反向写法：什么证据能推翻它）/ 范围边界（地理/时间/对象/排除项）。
- 看法隔离：立项书写成"没有作者"的文本；决策人自己的原有看法不进会话，由决策人**在会话外自己记下来**（一句话看法+信心百分比）。
- 第 0 优先信源：先查内部资产（案例库/知识库/既有调研产出），再搜外部。

## 0.5 问题体检（独立校验代理）

- 知识边界（白名单）：不上网、不看内部资产、不引用案例；不得引入立项书之外的事实/案例/数字/具体实体（抽象框架和类别除外）；只允许做：定义分析、逻辑拆解、问题改写、结构操作。
- 六项固定检查：
  1. **决策对象检查**：列出"真正要做的决定"的所有候选（做产品？进市场？机制值不值？选哪种模式？换场景？……），说明每个候选会导向多不一样的搜索范围。
  2. **复合问题拆解**：一个问题里塞了几件事 → 拆开，每件事各配"什么证据能推翻"的判据。
  3. **暗藏结论检查**：逐词找问题表述里偷偷藏着的未验证判断。能检验的 → 降级成明面上的待验证子问题；不能检验的 → 删除，且禁止进搜索关键词。
  4. **证伪方式检查**：判据需要的证据，公开渠道能不能拿到？（"主因是需求侧"这种归因判断、复购/营收数字，搜事实的代理凭公开网页能不能判定？）判据是否需要"总数/比例"才有意义？（"≥2 个失败"在总数是 3 个还是 300 个时意义完全不同）判据需要的总数必须在这个问题的搜索范围内找得到，否则判据不可执行——改判据或扩范围。
  5. **相邻问题**（三个方向，各 1-3 个）：上游问题（更根本的条件，它不成立商业问题就不用谈）/ 下游问题（买家实际为什么掏钱——可能和立项书写的不一样）/ 横向问题（换变量：对象、场景、客户、价值链位置是不是选错了）。
  6. **付费理由分类清单**：4-6 类，类别之间分得开，但允许一个买家同时有多重理由（多标签）；标注哪些立项书已提、哪些没提。
- **付费理由不设限**：不许预设"买家买的是研究者认为的价值"；必须允许搜索后发现真实付费理由是另一种。
- 产出：决策对象候选 / 暗藏结论清单 / 拆解方案 / 证伪判据审查 / 三向相邻问题 / "并且-或者"问题地图草案 / 固定一节"我没把握的地方"（禁止假装确定）。

## 0.6 定稿（决策人两个动作）

- **0.6A 盲定稿**（看到自己原有看法之前）：选决策对象 / 定问题地图 / 定"并且-或者"关系与硬条件、软条件 / 定必查项 / 定优先级 / **定门槛的两个必答题**——①按什么单位计数（产品还是运营主体）②运营状态怎么算（运营中/暂停/已关停/改名换主体/不详；门槛按"连续运营"还是"累计运营"）。全部记录版本。
- **0.6B 原有看法对照**：打开会话外自留档，只做对照检查（一致/冲突/遗漏）。**冲突本身不构成修改理由**（冲突恰恰说明原有看法可能错，是高价值信息）；允许修改的只有三类结构性遗漏——决策对象漏了 / 必要决策变量漏了 / 逻辑依赖漏了——且必须记修改记录（为什么改）。
- **【问题冻结】**：地图定稿后，本轮调研内问题不许改；新发现的问题进未决清单。
- **决定性锁定**：每个节点"对决策影响多大"在 0.6A 定稿时标好；事实代理只标"缺失+能不能搜到"；主代理核验时**按地图**标决定性；搜索中发现的新缺口一律进未决清单，不许反过来调搜索优先级。
- 三种状态：**正常推进 / 证据不足（问题成立，但公开渠道找不到足够证据）/ 问题作废（问题本身没法稳定定义，或判据没法操作化）**。判"问题作废"的决定权在决策人，且必须先处于"证据不足"状态、**提前锁定的检索路线清单全部跑完**（申报时附清单打勾记录）。事实代理只有申报权，没有决定权。

## 转写层（主代理把问题地图改写成搜索任务书）

- 转写原则：**0~0.6 可以复杂，1.0 必须简单**。"并且/或者"、硬软条件、触发条件、优先级，全部在转写时消化掉；事实代理拿到的扁平清单里没有逻辑判断、没有打分任务。
- **转写只消化不新增**：任务书里凡转写层新加的实质内容（门槛数值/时间窗改动/优先级安排）必须标【转写新增】并回头让决策人在 0.6A 确认——实测中"值得进入的门槛"就是越权实例。
- **立项书条目编号**：转写第一步，把立项书里的每一条要求（决策问题/证伪标准/范围边界每一项/排除项/对照要求）逐条摘出来编号（条目1、条目2……）；任务书每一项都标注它来自哪条条目。
- 任务书内容：对象定义/排除项/检索三向（正向+反向+用户声音）/优先级（P0 最优先、P1 次之、P2 有余力再查，P2 出现独立证据才升级）/分母要求/产出固定格式/预算与停止条件。
- **硬条件**：触发条件必须在 0.6A 全部预先写死在地图上；事实代理只有执行权没有解释权，不许中途发明停止条件。
- **必查项**：约束"搜没搜到"不约束"挖多深"——最低交付=摸一级（确认有没有）+状态标注（没到结论级的分支标"证据不足（摸一级）"）；要不要降级在 0.6A 定。
- **"或者"型分支的预算**：每条路径先给最低探索额度，之后按"哪条有新信息"分配深挖预算——防止"网上好搜的饿死不好搜的"（网上曝光多≠现实中重要）。
- **提前锁定的检索路线清单**：转写时产出——关键词族 / 信源类型 / 语言 / 时间窗，作为事实代理停止条件的机械验收依据（见执行规则第 9 条）。
- **【转写警报区】**（决策人过目任务书时**只看警报区**）。一套机制管三类毛病：
  - **漏抄**：编号后没有任何任务引用的立项书条目（集合运算机械检出）——防悄悄丢要求。
  - **改义**：①高危条目（原文含"分裂/条件"信号词——词表提前锁定，如：均需/两种/各/分别/且/或/不分/除外/仅/必须覆盖）没有附"保真记录"（保真记录=原文摘录+任务书落点编号+保留条件，三行以内）；②单个任务项挂了超过 3 条条目编号（防"万能条目"假覆盖——比如"全面研究该方向【条目1~8】"其实什么都没写出来）。
  - **空转**：任务项没落到能搜的字段（数字/日期/状态枚举之一）——比如"调查儿童留存"没说留存怎么算，代理只能搜到泛泛评论。
  - **警报区为空才许派事实代理**；警报条目由决策人裁决（补转写/改条目/明确放弃并记录）。
  - **警报区原始证据必须落盘**：漏抄的集合运算结果行、改义的保真记录三行、空转的判定行，作为警报区交付物的一部分（盲跑重测发现的记录缺口，防止"事后补记"与"真拦截"无法区分）。

## 1 事实收集（独立事实代理）

- **执行规则（≤9 条；超过 9 条=转写失败的信号，回转写层重做，不许硬塞）**：
  1. 只找事实（发生了什么），不做因果解释；别人的解释原句摘录进暂存区，不采信。
  2. 只按任务书执行，不自行推理任务之外的依赖关系。
  3. 按 P0→P1→P2 顺序执行；P2 出现独立证据才升级。
  4. 每条事实带网址+日期+数字口径（数字怎么统计的）；证据三级：强（财报/官方披露/法院文书）/ 中（平台可查数据）/ 弱（自称/转述）；**转手超过 2 道（如百科转引部委、部委又转引自报告）降为弱**。
  5. 独立信源计数：同一篇文章的转载记 1 个；引用同一出处的只算原始出处；只数能追溯到一手来源的。
  6. 没找到 ≠ 不存在。格式：`检索事实：截至[日期]，按既定检索范围与关键词[X]，未检出符合条件的[目标]`；另记一行 `未检出-[编号]|目标|范围与关键词|结果|日期`。
  7. 对照案例可比性优先，宁缺毋滥；可比性分三档（可比/部分可比/不可比，部分可比降权标注）；禁止为凑满"≥N 个"放宽可比性；**"≥N"是覆盖目标，不是真实性门槛**。检索动作必须做，产出如实记录（对照矩阵允许 1 比 0、2 比 1）。
  8. 分母纪律：记"≥N 个失败/成功"必须同时记总数+总数怎么定义+覆盖时间；总数不知道就标"分母缺失"。
  9. 停止规则：连续 2 轮只产生已记录事实的重复证明（没有新事实/新来源/新维度）→ 触发停止判定。**停止前逐项打勾提前锁定的检索路线清单，有没跑的项不许停**（换路径跑完再判）；全部跑完才能停，并输出停止声明（附清单打勾记录；停止=提前锁定的范围搜完了，≠事情查清了）。
- **检索三向必须各有动作**：正向（活着的产品+定价+销量）/ 反向（关停/转型/停更/纠纷）/ 用户声音（能追溯的公开渠道原句，多标签挂分类清单，禁止填"主导理由"；原句须标注和对象定义的相关性，不是本对象的原句单独归档不计入；**渠道类型不符时标注"经媒体转述"**）。
- **时间线状态节点**（2026-09-18 决策人修订）：平行时间线必须同时覆盖两类节点——正向（上线/改版/融资/扩张）与**负向（下架/停止更新/暂停运营/关停/转型/改名换主体）**。负向节点必须带时间点（至少精确到月；查不到就记未检出记录并标"时间不详"）；「运营中」的产品必须记录可追溯的起始运营时间——这是"连续运营 ≥N 年"门槛的唯一判定依据。只记正向不记负向 = 时间线覆盖不合格，主代理核验按缺失处理（幸存者偏差防线：产品何时死与何时生同样是证据）。
- **用户声音证据等级封顶**（2026-09-18 决策人修订）：一切用户声音（评论/帖子/访谈引述）默认封顶"弱"——非系统抽样、自选择偏差（极端体验者更愿意发声）、身份不可验。只可用于①假设生成与竞争假设排队②解释层线索；**禁止**作为门槛判定、最终裁决的独立依据；引用时必带"非系统抽样"标注。
- **10 个方面的事实覆盖**：背景/时间线/行动/结果/人物/资源/外部环境/产品业务变化/用户反馈/异常事件。缺的方面由事实代理标"缺失+能不能搜到"，主代理核验时按地图标决定性。**任务书里对象定义含形态排除（如"仅在线、排除线下"）时，事实表必须强制加"形态"列**。
- **枚举类任务的窗外声明**：纳入时间窗之外的案例必须声明理由（盲跑重测新增细则）。
- **【局限声明职责（收窄版）】**：事实报告"覆盖局限"声明里，凡属于**检索层**的缺失（搜了没搜到/渠道缺/语言缺）条目，自动列入未决问题清单；转写层丢失和改义的防线在转写警报区（事实代理根本不知道有条目被丢了，无从申报）。局限声明不许写成免责声明。

## 2 代理分工（谁知道什么）

| 角色 | 知道 | 不知道 |
|---|---|---|
| 主代理（转写+核验） | 全部 | ——（任务书+警报区必须决策人过目） |
| 校验代理（0.5） | 只看裸立项书 | 决策人看法/身份/任何证据 |
| 事实代理（1） | 只看任务书+执行规则 | 决策人看法/调研目的全貌/被转写层丢掉的条目 |
| 解释代理（2，未设计） | 四件套+未决清单+决策人看法 | 事实代理的搜索路径（防先入为主） |
| 红队代理（3，未设计） | 结论+关键证据+事实表 | 决策人看法和推理过程 |

交接物用固定格式，是唯一通道；未检出记录/审计附录不进解释层正文。

## 3 需求侧分层（规则按需承担）

### 触发边界（简单搜索 vs 全流程协议，2026-09-18 决策人修订）

- **默认 = 简单搜索**：直接搜、直接答（带来源链接），只执行常载级 7 条；不立项、不体检、不建矩阵。
- **升级触发**（满足任一，主代理必须显式提议"跑协议"，决策人确认后才启动）：①问题指向"做/不做/投多少"的决策（信号词：立项/赛道/值得吗/有没有发展空间/该不该/做不做）；②决策人点名"跑协议/深度调研/系统调研"。
- **强制降级保险丝**：决策人说"简单搜索"→ 一律按简单搜索执行，不得自行升级（哪怕问题看起来像调研）。
- **一句话判据**：不按"商业/非商业"分，按"结果是否用来做花真金白银的决定"分——查资料/确认事实/学概念/找工具 = 简单；立项/投入/赛道 = 协议。判据与内容领域无关，与用途有关（查"明朝海禁"是历史问题，但若用来决定投资方向就是决策搜索）。

- **常载级**（一切搜索，含日常快查）：看法隔离 / 双向检索 / 只记事实不记解释 / 未检出格式 / "≥N"是覆盖不是门槛 / 停止规则 / 独立信源计数。
- **触发级**（满足条件才生效）：未检出记录全文（未检出将作解释层关键输入时）/ 分母纪律（失败计数用于证伪时）/ 树外探查（≥4 轮检索时）/ 同景·跨域对照矩阵（涉因果成败判断时）/ 可比性三档（建矩阵时）。
- **全流程级**（结论投入真金白银的大决策）：0.5 / 0.6A / 0.6B / 三状态 / 代理分工 / 转写警报区 / 检索路线提前锁定。

## 验收判据（质量控制信号）

- 要给事实代理解释太多规则 = 转写失败，回 0.6 重做任务书。
- 执行规则超过 9 条 = 转写失败。
- 警报区没清空就派代理 = 违规。
- 事实报告局限声明出现检索层"未覆盖 X"却没有对应的未决清单项 = 违反局限声明职责。
- 好的问题地图能把复杂的决策逻辑压缩成简单的搜索任务；压缩不了 = 上层没转写好。
