# brain —— 唯一真源

> 定位：**人能找到、AI 能直接读写、换机能带走**的沉淀目录。
> 建立：2026-09-16（荣总确认：E 盘 + Git 私有仓库）

## 铁律

1. **真源只有一个，就是这里。** IMA 与 WorkBuddy 资料库都是从这里**单向派生**出去的检索层/交付层，**绝不回写**。
2. **密钥与运行时数据永不进来。** 见 `.gitignore`。
3. **引用别的文件只写指针，不抄正文。** 同一条规则全局只存一处。
4. **换机只需三步**：装 Git → `git clone <私有仓库> E:\brain` → 把 `00-身份与规则\*.md` 复制回 `~/.workbuddy\`。

## 与 WorkBuddy 的接口

WorkBuddy 要求规则文件必须位于 `C:\Users\Admin\.workbuddy\`，工作区记忆必须位于 `<工作区>\.workbuddy\memory\`。
本机**文件级符号链接不可用**（权限不足，已实测），因此只能用**目录联接（junction）**把上述位置指向本目录：

| 程序要求的位置 | 实际指向 |
|---|---|
| `<工作区>\.workbuddy\memory\` | `E:\brain\10-项目\<项目>\memory\` |
| `~/.workbuddy\skills\` | 用 Git 单独跟踪（暂留原位） |

> `00-身份与规则\*.md` 因无法做文件级链接，**物理上仍在 `~/.workbuddy\`**，靠本仓库的**第二个 Git 工作树**或换机时手工复制同步。
